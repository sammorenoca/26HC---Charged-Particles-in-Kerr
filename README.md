# 26HC---Charged-Particles-in-Kerr
Replicación en C++ del estudio de partículas cargadas alrededor de un agujero negro de Kerr con carga inducida y campo magnético externo. Incluye potencial efectivo, órbitas circulares e ISCO, un integrador simpléctico explícito, secciones de Poincaré, indicadores FLI y gráficas en Python, además de resultados nuevos comparando S4 con RK4.
